# 开发导师模块思维课件：新增方块世界第三个 3D 层级场景

## 用户原始需求

在现有“变形金刚／预制组件”和“乐高／基础零件创造组件”两个 3D 场景后，增加第三个《我的世界》式方块场景：使用所需材料方块组合成形状，先生成组件，再用组件生成具有特定功能的对象。

指定案例：

1. 小车：橡胶方块构成轮子，铁方块构成车架，塑料方块构成方向盘和座椅。
2. 瞄准观察道具：玻璃方块与金属方块构成瞄准镜，铁方块构成枪托与主体。

## 锁定的教学关系

```text
S02-A 预制组件：在既有组件约束内重组
S02-B 标准零件：先创造组件，再组合整体
S02-C 材料方块：把可编辑粒度继续下放，先塑形组件，再组合功能对象
```

“更细”指学习者能够介入的设计层级，而不是声称游戏方块的物理尺寸一定小于乐高。方块共享网格接口，但材料能力与行为不同；真实方块游戏也包含预制功能块。自建自由度越高，塑形、接口、测试和维护成本也越高。

## 实施边界

- 使用本地自托管 Three.js 与原创 BoxGeometry，不下载、热链或复制《我的世界》／Mojang／Microsoft 官方贴图、模型、Logo 或角色。
- 案例二只用于抽象模块层级教学，不呈现现实武器尺寸、内部结构、制造步骤或使用方法。
- 继续保留 HTML/CSS 无 WebGL 降级图、reduced-motion 和打印可读性。
- 保持 audience／teacher 物理分包与教师提示权限边界。
- 保留 S03—S16 稳定语义 ID，并将 S02-C 作为同一个 S02 源教学单元的第三页。
- 标准课仍为 60 分钟。

## 验收

- [ ] 18 张投屏页对应 16 个源教学单元，顺序为 S01、S02-A、S02-B、S02-C、S03—S16。

- [ ] 每个案例可依次切换材料方块、功能组件、功能对象三层，教师端与投屏端双向同步并刷新恢复。
- [ ] 小车与第二案例均完整呈现用户指定的材料到组件映射。
