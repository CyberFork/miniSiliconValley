# 重构课程总纲：PDMO 改为四类导师分工

## 原始记录

我突然明白了，PDMO不是学生的分工，而是导师的分工，之前都没想到，反而围绕学生展开了，这一块需要修改一下。写入到inbox的todo

应该是一个世界，两条双轨，三个游戏方式，四个导师分工，五个完整步骤，最后6分钟demo。更新内容写入todo

## 简要整理

重新梳理 Mini Silicon Valley 课程总纲：一个世界、两条双轨、三个游戏方式、四个导师分工、五个完整步骤，最后以 6 分钟 Demo 收束；PDMO 应定位为导师的专业分工，而不是学生的固定分工。

## 原计划下一步

盘点现有课程文档、产品界面和课堂机制中所有把 PDMO 表述为学生分工的内容，并按新的“一二三四五六”总纲形成修改清单。

## 关键控制点

一个世界；两条双轨；三个游戏方式；P／D／M／O 四类导师职责；五个完整步骤；6 分钟 Demo；学生参与和协作方式需要重新表述。

## 来源上下文

当前对话；Mini Silicon Valley 项目课程结构与游戏设计讨论

## 完成回执

- 已建立课程与产品共同真值文档，明确 P／D／M／O 是产品、开发、市场、运营四类**导师专业分工**，学员统一为 Young Builder 团队成员，不再固定分配 P／D／M／O。
- 已把“一个世界、两条双轨、三个游戏方式、四个导师分工、五个完整步骤、六分钟 Demo”落实到 5 个宏观步骤、13 个可人工验收的 LIVE RUN 脚本块。
- 已同步修正导师席位、学员席位、控制台文案、随机信息卡、个人 RP、个人钱包、团队资金与最终结算等实际界面和运行状态。
- 已完成真实 API 流程与浏览器 4＋4 席位视觉验收，不再只停留在课程表述层。
