# 实现课程编辑器与 Alpha 调试课程即时同步

## 原始记录

todo：我希望当前的课程编辑器可以和真实课程相互结合，也就是我可以使用课程编辑器编辑之后，正在alpha中调试的课程可以马上同步新内容。alpha的控制面板当前可以前进，但是也需要有可以后退和全部刷新的功能，从而来更新最新更新的课程内容方便调试

## 简要整理

把课程编辑器从独立内容编辑工具连接到真实的 Alpha 调试 Run。编辑器保存或发布课程修改后，正在运行的 Alpha 课程应能获取最新内容，不必删除并重建 Run；Alpha 控制面板除现有“前进”外，需要增加“后退”和“全部刷新”，让导师能反复验证课程步骤、口播、卡牌、学员动作及系统动作。

## 目标形态

1. 课程编辑器与真实 Alpha 调试课程使用同一套课程 JSON／课程版本来源。
2. 编辑器完成一次有效更新后，Alpha 控制面板能够识别存在新版本，并加载最新课程内容。
3. 已创建的 Alpha Run 不需要因为内容调整而重复创建，适合连续快速调试。
4. 控制面板形成三个基础调试动作：
   - **前进**：进入下一个课程区块或步骤；
   - **后退**：返回上一个课程区块或步骤，便于重复验证；
   - **全部刷新**：强制 Alpha Run 及相关测试窗口重新读取最新课程内容并刷新显示。
5. 同一 Alpha Run 的导师控制台和所有学员测试窗口应显示一致的课程版本与当前位置。

## 同步流程设想

1. 编辑器保存并通过 Schema／引用完整性校验。
2. 系统生成新的课程修订号或内容版本标识。
3. Alpha 控制面板收到“课程内容已更新”的提示。
4. 导师点击“全部刷新”，或按最终确定的 Alpha 自动同步策略，加载最新修订。
5. 八个测试窗口同步刷新，并确认当前显示的课程版本一致。
6. 导师可使用“后退／前进”反复测试修改后的区块。

## 功能要求

### 编辑器与 Alpha 连接

- 编辑器清楚显示当前正在编辑的课程 ID、修订号和对应 Alpha Run。
- 保存失败、内容校验失败或同步失败时必须显示明确原因，不能让 Alpha 混用半份新内容。
- 控制面板显示“当前运行版本”和“编辑器最新版本”，便于判断是否需要刷新。
- 同步后应能确认成功加载的课程修订号和更新时间。

### 后退

- 可以从当前区块返回到上一可执行区块，并同步所有测试窗口。
- 到达课程起点时按钮禁用，不产生负数位置或非法状态。
- 后退后再次前进应得到可重复、可解释的结果。
- 需要明确哪些运行数据随位置回退，哪些学员提交、抽卡结果和测试记录仍保留。

### 全部刷新

- 强制重新获取最新课程 JSON、步骤结构、导师口播、卡组和界面文案。
- 所有 Alpha 测试窗口收到统一刷新信号，避免部分窗口仍使用旧版本。
- 刷新期间显示加载状态；成功后显示统一版本号，失败时保留最后一个完整可用版本。
- 需要区分“刷新内容但尽量保留调试进度”和“彻底重置 Run”的语义，避免一个按钮同时承担两种不可逆操作。

## 待确认的设计边界

- “编辑后马上同步”是编辑器保存即自动推送，还是保存后由导师点击“全部刷新”确认加载。
- 正在显示的区块被删除、改 ID 或移动后，Alpha Run 应保持原位置、寻找最近合法位置，还是要求重新选择。
- 新旧课程 Schema 不兼容时如何阻止热更新并提供回滚。
- 后退是否只改变课程指针，还是需要回滚倒计时、发牌、学员提交、评分和系统动作。
- “全部刷新”是否保留当前步骤、学员席位和调试数据；彻底清空应提供独立且有确认提示的操作。
- 多位导师或多个控制台同时操作前进、后退、刷新时的冲突和最终一致性。
- 此能力只开放给 Alpha 调试 Run，不应让正式课堂在未确认时自动切换课程版本。

## 下一步

盘点课程编辑器的保存／发布链路、课程版本模型、Alpha Run 的课程快照方式、控制面板推进接口和八窗口同步机制，先定义热更新、后退及全部刷新的状态转换契约，再实施接口和界面。

## 验收标准

- 在编辑器修改一段导师口播或学员动作后，现有 Alpha Run 无需重建即可加载新内容。
- 控制面板同时提供前进、后退和全部刷新，并有明确的可用／禁用／执行中／失败状态。
- 点击后退后，导师控制台与全部已打开测试窗口进入同一上一位置。
- 点击全部刷新后，所有测试窗口加载同一个最新课程修订号，不出现新旧内容串用。
- 内容更新失败时继续使用最后一个完整版本，并能看到失败原因和重试入口。
- 正式课程不会因 Alpha 编辑器保存而被静默热更新。
- 对前进、后退、刷新、版本冲突、区块删除／改 ID、断线重连和多人并发完成自动化或端到端测试。

## 关键控制点

课程 JSON 真值来源；草稿与已发布版本；Alpha 热更新触发方式；当前步骤与新版结构的映射；后退的数据回滚边界；刷新与重置分离；八窗口版本一致性；失败保底与回滚；多人并发控制；正式课堂隔离。
