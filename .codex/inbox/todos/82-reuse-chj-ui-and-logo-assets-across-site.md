# 统一全站 Logo 资产并将左上角 Logo 设为主页入口

## 原始需求

使用 `chj` 分支中已有的相关 UI 和 Logo 资产，补齐当前已实现网站中缺失、占位或表现不一致的 Logo，形成统一的品牌入口和页头展示。

补充要求：**所有页面左上角的 Logo 都必须可点击，并在当前标签页回到 `https://minisv.vip/` 主页。**如当前页面没有 Logo，需要在不破坏当前布局的前提下补充紧凑版左上角品牌入口。

## 目标

- 优先复用 `chj` 分支中已经完成的 Logo、图形元素和相关 UI，避免重复制作新品牌资产。
- 将网站内各个入口的 Logo 来源、比例、尺寸、留白、色彩和深浅背景变体统一。
- 将“左上角 Logo → MiniSV 主页”确立为全站稳定导航契约，不再让不同子系统的 Logo 分别指向课程大纲、子项目首页、旧域名或失效路径。
- 不整页照搬 `chj` 分支 UI；只提取已确认的品牌资产和可复用组件，并与当前站点设计系统融合。

## 调研范围

### 1. 盘点 `chj` 分支

- 找出 Logo 原始资产：SVG、PNG、WebP、favicon、黑白／深浅色变体。
- 找出引用 Logo 的页头、导航、课件封面、水印和页脚组件。
- 确认哪些是正式品牌资产，哪些只是 PM HTML/PPT 课件的特定视觉元素。
- 记录资产路径、尺寸、颜色、背景假设、字体依赖和授权／来源。

### 2. 盘点当前站点缺口

检查下列页面的桌面端和移动端：

- 主页与全站顶部导航。
- `/framework/`课程大纲。
- `/classroom/`正式课堂。
- `/alpha/`内部测试控制台及导师／学员席位。
- `/control/` 和 `/control/editor/`。
- `/qa.html` 及其他已发布工具页。
- 404、加载页、登录页、favicon 和分享预览图。

对每个页面标记：缺失、占位、拉伸变形、颜色错误、清晰度不足、对比度不足、链接错误、点击无反应或多套 Logo 并存等问题。同时检查页面左上角是否存在可见、可聚焦的主页 Logo 入口。

### 3. 全站主页链接契约

- 页面左上角 Logo 的目标统一为根路径 `/`，在生产环境解析为 `https://minisv.vip/`。
- 使用真实 `<a href="/">`，不只依赖 JavaScript `onclick`，保证键盘、辅助技术和 JavaScript 失效时仍能返回主页。
- 默认在当前标签页打开主页，不新建标签。
- 无论页面来自 Next/Vinext、静态 HTML、LIVE RUN controller、Alpha console 还是独立课件包，都使用同一绝对站内根路径，不根据当前相对目录错误跳转。
- Logo 链接需要可键盘聚焦，具有清晰的 focus-visible 样式和 `aria-label="返回 Mini Silicon Valley 主页"`。
- 如果课程编辑器存在未保存 Working Copy，或课堂正在执行不可恢复动作，仍保留 Logo 返回主页的契约，但先触发统一的离开确认，防止意外丢失未保存内容。

## 实现方案

1. 将确认的 Logo 原始文件收口到主工程单一公共资产目录，不让多个子项目各自复制一份。
2. SVG 优先；需要位图时保留高分辨率源文件，并生成适合网页的压缩版。
3. 建立共享 Logo 组件，支持：
   - 深色／浅色背景。
   - 图形标／完整字标。
   - 页头、紧凑导航、课件封面和 favicon 等尺寸变体。
   - 固定宽高比、安全留白和不可拉伸规则。
4. 按页面逐一替换占位或错误 Logo，不改动这些页面的课程数据、运行状态和业务逻辑。
5. 对 PM HTML/PPT 课件内的专用装饰元素单独命名，不将其误当作全站 Logo 或全局设计 token。
6. 同步更新 favicon、Web App manifest 和需要的 Open Graph 图片，确保浏览器标签、收藏和链接分享一致。
7. 将全部页面左上角 Logo 包装为返回 `/` 的标准链接；没有页头 Logo 的页面补充紧凑入口，并处理未保存编辑状态的离开确认。
