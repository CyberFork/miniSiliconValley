# Admin 学员管理多选与安全批量删除

## 用户需求

> https://minisv.vip/account/ 学员管理中，我希望能够实现多选功能，方便我批量删除。优先执行这个，然后继续todo

## 实施范围

- 学员列表每行增加键盘、鼠标和触摸均可操作的选择框；支持选择／取消本页，并允许跨搜索和分页保留选择。
- 始终显示已选数量和清空选择；没有选择时禁用批量删除。
- 批量删除前通过服务端重新检查课堂、作品、学习、声望、资金和验收依赖。
- 二次确认展示具体目标与影响：无历史依赖的账号进入删除清单，有历史证据的账号明确列为保留并说明原因。
- 使用一次明确的确认文字执行批量删除，不要求逐个输入账号；服务端按实时可删除数量校验确认文字。
- 服务端仍在每个实际删除前再次执行依赖检查。阻断账号保留，不误删导师、Admin、课堂、课程、课件或历史证据。
- 仅平台 Admin 可调用批量预览和删除 API；复用既有账号删除规则，不建立第二套身份或依赖判定。

## 验收

- [ ] 从 `/account/` 的“学员管理”可以勾选多个学员并一次删除。
- [ ] 本页全选、取消、跨搜索／分页选择和已选数量显示正确。
- [ ] 删除弹窗完整展示可删除与保留账号，二次确认未完成时不能提交。
- [ ] 无依赖账号真实删除；有历史依赖账号保留并说明原因。
- [ ] 非 Admin 的 UI 和 API 均不能执行批量删除。
- [ ] 隔离 D1 单元和真实浏览器链路通过，生产只做非破坏性入口复验。
- [ ] 完成构建、部署、生产复验和交付记录后再标记完成。
