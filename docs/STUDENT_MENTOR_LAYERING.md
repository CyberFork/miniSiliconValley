# 初中生—导师双层教学节奏

## 设计原则

- 先行动后命名：每个概念必须来自刚发生的具体经历。
- 学员负责看、说、做、改；导师负责抽象、追问、可选的PDMO方法论和经济规则。
- 一轮固定四拍：**具体经历 → 学员观察与表达 → 导师命名抽象概念 → 学员立刻再用一次**。
- 不把身份、卡面观点或历史结局当作唯一答案；允许依据证据形成不同世界线。

## 信息分层

学员看到：自己的案例身份、自己随机抽到的3张卡、公开情报、当前挑战目标、工具、钱箱和任务结果。学员不需要阅读公式或复杂卡文案。

导师看到：完整章节内容、全部12张信息卡、全部身份、未抽中挑战、DM话术、可选PDMO脚手架、公式、经济约束、史实来源和揭晓条件。导师在体验后用一句话命名概念，再让学员应用。

身份池与信息卡池完全独立：身份随机抽取；每人从完整12张章节牌池随机抽3张，信息卡不按角色绑定。

## 13阶段动作映射

下列名称与 WebApp 的 13 个阶段一致。每个阶段都必须跑完“做→说→命名→再做”，不允许导师在学员行动前长讲概念。

1. **四人到齐（lobby）**：学员核对队伍ID和4个名字→说出还缺谁→导师命名“开局条件”→学员完成最后一次邀请或确认。
2. **拿到角色任务（identity）**：学员读目标、担心和能力→用一句话复述→导师命名“情境视角”→学员重说一次“我能为团队做什么”。
3. **打开三张线索（private-read）**：学员独立读3张→分成确定与不确定→导师命名“事实边界”→学员重新标记一张卡。
4. **讲给队友听（intel-brief）**：学员用30秒复述→队友追问卡上依据→导师命名“来源与可信度”→学员补充依据后再发布。
5. **把线索连起来（intel-network）**：学员做人物、困难和证据便签→用“因为”连线→导师命名支持、限制、矛盾等关系→学员改正一条线。
6. **用五句话说清问题（dm-gate）**：学员写谁、哪里卡住、证据、未知、下一步→口头说一遍→导师命名用户、损失和可验证问题→学员修改模糊的一句。
7. **商量怎么一起做（pdmo）**：默认四人作为一个团队说清第一步、谁先做、谁支援→直接进入共同攻坚；只有进阶班或团队确实需要责任边界时，导师才命名 P/D/M/O 并让学员自愿认领。未分工不是关卡失败。
8. **第一次试做（challenge-one）**：学员读任务与突发情况并提交做法→说出如何判断有效→导师命名目标、资源、证据与停止条件→学员补强一个空格。
9. **根据反馈改一次（challenge-two）**：学员对照第一次结果→指出一处不够好→导师命名“迭代”与证据/逻辑/执行/协作→学员改一项后提交第二版。
10. **算账和选工具（growth）**：学员看收支、投票选工具、感谢队友→说出一笔钱和一项帮助的依据→导师命名收入、成本、RP与机会成本→学员重做一次工具投票或记账解释。
11. **我们的选择 vs 历史（history）**：学员先写自己会怎么做并锁定→揭晓后说一同一异→导师命名“反事实对照”→学员用新认知重新评估一个选择。
12. **说清学到和下一步（debrief）**：学员回答6个短问题并写两天任务→说出自己改变了什么→导师命名证据意识、协作与迁移→学员把下一步改成有时间、交付和检查办法。
13. **完成六分钟发布（completed）**：学员挑作品、排练并发布→说清问题、线索、做法、结果、下一步→导师命名完整 PDMO 闭环→学员根据一条现场反馈改正作品或下一步。

## DM逐段话术模板

- 经历前：“请先做这个动作，不必说术语；留下一个看得见的结果。”
- 表达时：“请用‘我看到、我猜测、我不确定’说，并指出卡号或作品证据。”
- 命名时：“刚才这个现象，在导师语言里叫____；它解释的是____，不是标准答案。”
- 再用时：“现在立刻把这个概念用一次：改一条线、一个决定、一个原型或一笔预算，并说出改动。”

## 卡片事实边界

卡片须标明事实、观点、约束、来源和可信度。身份持有者只拥有视角，不拥有同角色绑定卡；未抽中的卡和挑战不向学员泄露。导师可见完整牌池，学员只能看到自己的卡与已公开内容。

## 验收清单

- [ ] 每阶段都有具体动作、学员表达、导师命名和再次应用。
- [ ] 13阶段顺序与课堂计时一致。
- [ ] 身份与卡牌分别随机；每人从完整12张牌池抽3张。
- [ ] 学生视图无DM指南、未抽中挑战、复杂原始卡文案。
- [ ] 导师端保留可选PDMO、方法论、公式、经济规则与史实来源；学员未分PDMO也能提交挑战行动。
