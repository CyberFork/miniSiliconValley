# DM/导师课堂手册（FACILITATOR_GUIDE）

## 课堂边界（必须讲明）
- `ORIGINAL TIMELINE` 不可改写：史实只读。
- `PLAYER TIMELINE` 可改写：世界线是教学模拟。
- 评分逻辑来自过程与复盘，不以“猜对历史”判定。

## 90 分钟完整课堂 Runbook
1. **0–10′** 开场：解释时间线边界、资源模型、复盘规则。
2. **10–25′** 地图浏览：按年份移动时间轴，读若干事件。
3. **25–40′** 分组角色分配，证据阅读。
4. **40–55′** 小组决策与证据锁定。
5. **55–65′** 生成玩家世界线。
6. **65–75′** 打开原始历史对照，做异同分析。
7. **75–87′** 完成现实任务（交付清单）。
8. **87–90′** 档案冻结与下一步行动。

## 15 分钟快速演示 Runbook
1. 说明“原始 vs 玩家”边界。
2. 快速对照 1939/1968/1998/2026 地图建设。
3. 从“车库第一单”跑到史实对照，展示现实任务验收条件。
4. 演示学习档案、检查点和 JSON 设备交接。

## 页面操作卡

- **历史世界**：拖底部年份滑杆；用 `←/→` 逐年、`PageUp/PageDown` 跨 10 年、`Space` 播放。地图可拖动、滚轮/双指/按钮缩放。
- **史实卡**：点地图热点或左侧事件；在 Source Vault 打开来源。黄色 `!` 表示可开关卡。
- **关卡**：至少收入 2 条证据才可决策。史料链接在决策后解锁，不要提前让学员搜真实结局。
- **补证**：若行动尚未解锁，让学员点击路线旁的“去补读”，按黄色高亮卡补证；不要替学员选择路线。
- **学习档案**：上课前“建立检查点”；设备交接前“导出 JSON”；不要把未成年人的真实身份写进复盘。
- **DM 手册**：可从关卡卡组直接开本；使用页面顶部“打印 / 导出 PDF”生成纸质备份。

## 课堂主持协议（DM Protocol）
- 定界：先说本轮已知/未知。
- 放证：只给当前场景需要的证据。
- 追问：要求“哪条证据撑住你的选择”。
- 裁决：按选择 + 证据 + 约束生成，不按导师偏好。
- 对照：让学员先复述自己世界线，再看历史。
- 迁移：要求现实行动可执行（时间、验收点、负责人）。

## Dossier（档案）教学命令
- 建立检查点（checkpoint）
- 现场导出 JSON
- 失败重玩：重玩本关会覆盖该关结果
- 任务转接：导出后换设备导入，核对关卡数与资源

## 安全与合规
- 不采集不必要个人信息。
- 录播/访谈提前签署授权。
- 未成年人不承担付款与合同义务。
- AI 输出必须经团队复核后再用于公开。

## 常见故障处理
- 断网：核心游戏数据本地打包，可继续浏览；外链来源放在恢复网络时打开。
- 误选：立即重玩，不强制重开整课。
- JSON 导入失败：查看错误提示（版本、字段、大小限制）。
- 浏览器清空：需重新导入上一次导出的档案。
