# 课件文字与发布包解耦

P1 r13、P2 r6 起启用 shared-v1。课件包版本控制布局、动画和教学原文；导师编辑通过同一 deck 的共享文字流保存，不随包版本清空。

## 导师操作
- 从 /course/ 打开最新教师课件，直接点击文字弹窗编辑。保存后刷新仍保留，当前投屏同步。
- 教师新打开页面默认加载最新文字；历史选择只读，不自动覆盖其他播放会话。
- 新版原文改变或字段移除时，工具栏显示待确认项：保留修改／采用新版原文／复制内容。未确认内容留在历史，不猜位置套用。
- r12 及以前保留历史包和旧文字快照；迁移后不再允许在旧包新增编辑，请到最新版继续。
- 本地预览保存到本地 SQLite，不冒充已经发布线上。

## 后续开发不可破坏的约束
1. `deck.id`、`slide.id` 是长期身份，不因发布 revision 重命名。
2. 静态正文的 `data-msv-field` 是持久字段 ID。移动、改字时保留；新语义的新字段必须分配新 ID。删除过的 ID 不复用。
3. `python3 scripts/courseware_text_fields.py <deck-data.js> --annotate` 只给新字段分配 ID；保留每页 `textFieldSequence`。
4. 新包注册新的 catalog 项，fields 从 `--catalog` 结果按 id→original 生成；不要改历史 catalog。构建会比对原文与 ID，缺失／重复／漂移即失败。
5. DOM 数字路径仅用于一次旧数据恢复；不再作为新版文字身份。
6. 保存使用 deck 级 CAS，跨包同时保存也只有一方成功；恢复原文保留 tombstone，禁止旧修改复活。

## 一次性恢复与部署
- `ops/scripts/migrate-courseware-text.py` 在既有部署流程停止写入服务后运行，完整 SQLite 备份、BEGIN IMMEDIATE 导入；旧行不改不删。
- 按旧快照时间顺序重放每处实际变化，合并不同包修改，后一次显式编辑优先；未知位置保留为冲突。
- 作者与时间沿用原始事件，保存来源 base；`courseware_text_imports` 记录源摘要使重复部署幂等。若回滚后旧系统产生新写入，检测后中止发布要求核对，绝不悄悄跳过。
- 迁移映射来自生产已有历史课件源码，只接受同页唯一原文匹配；标题按稳定角色匹配。结构／语义不确定的内容不自动附会。
- 纯升级不得把用户文字硬写回教学原文来冒充数据迁移。

## 验证
平台 shared-v1 测试、恢复/稳定字段测试、本地 HTTP 测试，以及 CUA 的实际点击→弹窗→保存→刷新→换包并移动 DOM→原文冲突→确认沿用。
人工试讲／View/UI 验收仍需用户完成。
