## 需求与边界

入口 `/course/` 按产品 P、开发 D、市场 M、运营 O 导师分组，而非平级罗列。只改只读目录呈现，不修改课件文件、版本、课堂状态或权限。

- 使用已有 `mentorRole` 字段作为归属，不按标题猜测；先保留原可见性筛选，再分组。
- 固定四组，显示各组数量和空态；顶部锚点导航直接跳至分区，不新增中转页。
- 开发组按 P1《模块思维》→ P2《立棍》排列，新增包在其后保持原有次序。
- 保留精确课件链接、导师控制台入口以及服务端权限，学员不显示教师入口。
- 版本详情改为可展开，不让 packageId / digest 占据卡片主体。
- 明确设置浅底深字、键盘焦点、触摸目标和响应式布局。
