## 2. 测试组合

每一种实际执行的组合各填写一份本模板：

- `☐ macOS Safari：普通点击、Enter、Cmd＋点击、右键新标签、前进／后退／刷新`
- `☐ Windows Chrome／Edge：普通点击、Enter、Ctrl＋点击、中键、右键新标签、前进／后退／刷新`
- `☐ iPad Safari：单次触摸、长按新标签（若系统提供）、系统返回手势、旋转后继续`
- `☐ Android Chrome：单次触摸、系统返回键／手势、旋转后继续`

未实际具备的输入方式标记 `BLOCK`，不能依据另一平台推断通过。
