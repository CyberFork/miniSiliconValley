# WHY-取舍交互回归修复（P1 r17）

## 根因与修复
- 真实 Chrome 复现：从预制玩具切到乐高，按钮和文字更新，但画面仍为汽车；启动传送带无对应视觉动作。
- `data-module-3d` 实际映射为 `dataset["module-3d"]`，不是 `dataset.module3d`。原复用比较两端均为 undefined，错误保留了不同类型的渲染器。
- 改为 getAttribute 比较真实场景类型；同类型继续保留 WebGL、相机与平滑模式过渡，不同类型使用新场景并淡出旧场景。
- 演示未删除，不新增无关交互。P2 r6使用其已发布 lesson-tools.js 兼容快照，保持包字节不变。

## 检查
- 原生 Chrome 本地投屏页逐项观察：预制汽车/飞机、乐高多方向拆解与拼回、材料方块/整车、移动/拾取/背包合作均显示对应三维场景，按钮有实际视觉变化。
- 预制玩具仍用5秒拆解重组；乐高拼回结束后才启动合作运动。
- 新增真实函数回归测试：12个跨类型组合、同类型相机/节点保留、快速切换、旧节点清理；变异回滚为旧比较方式时测试必须失败。
- P1教学内容、389个稳定字段、slideIds不变；沿用共享文字内容，不重写用户编辑。
- 工程验证不替代导师试讲验收。
