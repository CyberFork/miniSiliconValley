# 小车道具在当前车位丢弃

- 统一 S06 试玩与方块工坊的丢弃规则：使用点击时最新小车 x/z，放在该处地形表面；不回到道具初始出生点。
- 共享 gameplay state 增加可选 droppedPositions；拾取检测、3D 物品、持久化和双屏状态都使用同一坐标。旧存档缺少该字段时仍用原出生点。
- 丢弃后须先离开拾取范围，再返回才能再次拾取，避免立刻捡回。
- 修复工坊按钮闭包捕获旧车位：每次渲染更新最新 snapshot，点击时读取。
- Safari 原生 UI 隔离样例：金币出生点为 x=2,z=0；把持有金币的小车移至 x≈3.614,z≈5.038，点击丢下后背包为 0/2，金币出现在 x≈3.614,z≈5.038、地面 y=.35，与当时车位一致，并未立即重新拾取。
- 69 项小车/工坊测试、88 项部署测试通过。测试页仅在本地 dist，不发布线上。
