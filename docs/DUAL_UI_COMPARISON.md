# MINI硅谷 UI 收敛记录

## 当前结论

双 UI 对比阶段已经结束。自 2026-09-08 起，Mini Silicon Valley 全站只使用最新的 **Adventure（冒险）UI**：

- 不再显示 `UI｜当前｜冒险` 切换器。
- 不再接受 `?ui=classic` 或浏览器历史偏好切回旧版。
- 不再在页头预留主题切换槽位。
- 课程、账号、Classroom、Course Studio、LIVE RUN 与静态导航共用同一套冒险视觉语义。
- 页面原有信息架构与交互布局仍由各页面负责；共享皮肤只统一颜色、材质、边框和阴影。

这次收敛解决了浮动切换器覆盖 Classroom 顶部导航的问题，也避免同一个产品在不同浏览器中因本地存储而呈现不同界面。

## 视觉语义

- 品牌蓝：结构、主导航和主动作。
- 薄荷绿：确认、前进和已完成。
- 黄色：线索、未知、奖励和解锁。
- 红色：危险、警告和不可逆操作。
- 地图、人物和历史现场使用位图；教学文字、按钮和标签继续使用真实 HTML。

## 技术契约

- 唯一根属性：`html[data-msv-theme="adventure"]`。
- 共享资源：`/ui-theme.css`、`/ui-theme.js`。
- `ui-theme.js` 只负责固定冒险主题、识别浅色/深色业务表面，以及在方法页和家长页补充导师课件入口；它不会创建任何主题控件。
- 旧 `minisv.ui.theme` 本地存储值会被清除，旧 URL 参数不会改变主题。
- Next 应用在服务端 HTML 中直接声明冒险主题，避免首屏闪回旧皮肤。
- 静态发布页由 `package_release.py` 幂等补齐冒险根属性与共享资源。
- Classroom 实例、LIVE RUN 与席位页标记为深色业务表面；门户、账号与编辑器保持浅色业务表面。
- 同事独立交付的 P 导师 CoursewarePackage 仍按原字节发布，不经过主应用皮肤装饰。
- 冒险皮肤不得修改已验收布局几何，不得制造额外工具栏、浮层或空白占位。

## 回归验收

- 任一页面的根主题必须为 `adventure`。
- DOM 中不得出现 `#msv-ui-switch`，页头不得出现主题占位槽。
- 带 `?ui=classic` 打开页面仍然保持冒险主题。
- Classroom 顶部的“我的席位 / 主控 / 投屏 / 成员 / 退出”保持可见、可点击且不被覆盖。
- 桌面与手机视口均不得产生横向滚动。
- 深色课堂和浅色编辑页面应保留各自可读的颜色对比度。
- `prefers-reduced-motion` 下关闭非必要动画。

## 历史说明

此前双 UI 模式用于在不破坏既有布局的前提下对比当前版与冒险版。完成团队评审后，冒险版被确认为产品唯一视觉；旧切换逻辑、键盘切换、浮动 fallback 与页头槽位现已退役。
