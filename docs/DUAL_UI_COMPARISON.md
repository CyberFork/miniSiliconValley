# MINI硅谷双 UI 对比模式

## 目的

在不破坏已验收界面的前提下，让团队在同一个网址内对比两套视觉：

- **当前**：保持现有布局、颜色和组件表现。
- **冒险**：依据 `mini-silicon-valley-design` 规范，强化像素冒险世界、蓝绿主色、暖纸张网格、地图、任务卡和实体按钮。

首次访问默认使用“当前”。切换结果保存在同域名的 `localStorage`，刷新或进入其他 MiniSV 页面后继续生效。

## 使用

1. 打开 `https://minisv.vip/` 或任一主要页面。
2. 使用右上角 `UI｜当前｜冒险` 切换。
3. 使用键盘时，可聚焦切换器后按左右方向键切换。
4. 临时强制预览可以使用：
   - `?ui=classic`
   - `?ui=adventure`

URL 参数只决定本次页面初始模式；主动点击切换后才会写入持久偏好。

## 视觉语义

- 品牌蓝：结构、主导航和主动作。
- 薄荷绿：确认、前进和已完成。
- 黄色：线索、未知、奖励和解锁。
- 红色：危险、警告和不可逆操作。
- 地图、人物和历史现场使用位图；教学文字、按钮和标签继续使用真实 HTML。

## 技术边界

- 根属性：`html[data-msv-theme="classic|adventure"]`
- 存储键：`minisv.ui.theme`
- 共享资源：`/ui-theme.css`、`/ui-theme.js`
- 静态发布页由 `package_release.py` 幂等注入。
- Classroom/Auth 的服务端 HTML 由 gateway 注入；RSC/JSON/API 内容不受影响。
- LIVE RUN、课程编辑器、八席控制台和席位页显式加载共享资源。
- 深色控制台通过 `data-msv-surface="dark"` 保持深色语境，不会被错误改成学生端浅色页面。
- 页面声明 `data-msv-theme-slot` 时，切换器进入既有页头操作区；没有槽位时使用不参与布局的右上角浮层，禁止生成全宽工具栏或为页面补空白边距。
- 冒险主题是纯皮肤层，只改变颜色、背景、材质、边框颜色和阴影，不修改已验收布局几何。
- 课程编辑器使用工作区容器查询；当侧栏或浏览器缩放压缩编辑区域时，卡组、表单和发牌预览按实际容器宽度自动堆叠。
- 编辑器显式声明 `[hidden]{display:none!important}`，已载入课程后不会残留占位空状态。

## 回归验收

- 当前模式除新增切换入口外，不应改变既有页面。
- 两种模式均不得产生横向滚动。
- 桌面与 390px 手机视口中切换器必须可见、可点击、可键盘操作。
- 切换、刷新和跨页面后偏好保持一致。
- `prefers-reduced-motion` 下关闭非必要动画。
