# 课程语义（权威）

本文件是当前课程口径的唯一权威说明。其他文档中出现的“项目六步”或旧阶段名称，均属于历史旧版六步资料，已被本语义替代。

## 总体结构

- **一世界**：同一套可核验科技史世界，学员在其中探索并把能力迁移到现实。
- **两条双轨**：历史真实史轨（ORIGINAL TIMELINE）与学员平行世界轨（PLAYER/PARALLEL WORLD）并行；同时以历史世界与现实创业两条学习轨组织体验。
- **三层学习引擎**：探索、决策、建造。
- **课堂桌游机制映射**：探索引擎通过毛线信息网络把私密线索连成证据；决策引擎通过美式攻坚推动团队在压力下取舍；建造引擎通过德式经营衡量资源投入、交付与反馈。三种机制服务于三层引擎，不是额外的课程步骤。
- **四类导师分工**：P（产品）、D（开发）、M（市场）、O（运营）四条导师专业线；这些字母只描述导师，不规定学员身份或固定团队分组。
- **学员身份**：所有学员统一称为 **Young Builder**。

## 五个学习步骤

1. **找真问题**：从真实场景与证据中发现值得解决的问题。
2. **定真方案**：比较方案并依据证据作出取舍。
3. **做真产品**：制作可运行的最小产品并验证核心任务。
4. **进真市场**：让真实用户接触产品，测试渠道与价值表达。
5. **跑真运营**：根据反馈持续交付、迭代、复盘并建立可持续运行机制。

## 终局

**Demo Day 是独立终局，时长六分钟，不是第六步。** 学员展示真实产品、证据链、关键取舍与下一步计划；展示后进行反馈和复盘。

## 证据与世界线边界

- **真实史**：ORIGINAL TIMELINE，由带来源的历史事件提供；不可被玩家改写。
- **平行世界**：PLAYER/PARALLEL WORLD，由玩家选择和规则化模拟生成；不是史实，不回写真实史。
- 教学材料必须明确写全证据边界：**F 有来源**（可追溯事实）、**R 课堂模拟**（角色扮演／平行世界）、**G 我们猜的**（待验证推测）、**U 还不知道**（当前未知）；不得只显示四个字母，更不得把模拟、推测或未知冒充历史事实。
- 历史关卡内部可使用六幕循环（入场→调查→决策→平行反馈→史实对照→带回现实），它不是课程学习步骤。

## 迁移说明

仓库早期“项目六步”（找问题、识别真问题、想解决方案、MVP+VC、运营+品牌、Demo Day）仅作为历史旧版资料保留，当前内容、界面和教学编排应遵循本文件的五步与独立 Demo Day。
