# 体系结构与状态机

产品与体验基线：[`UX_PRODUCT_TRUTH.md`](UX_PRODUCT_TRUTH.md)。

## 组件与边界

- `course.py`：唯一 LIVE RUN 课程注册表，定义 Google 五步/13 块与饿了么五步平行世界战役 5 步/13 块、导师顺序、证据门槛和座位任务；`--write-json` 同时生成 `live-run-script.json` 与 `live-run-script-eleme.json`。
- `controller.py`：本地 HTTP 控制台与状态机。默认 127.0.0.1:18765；使用原子 JSON 状态文件，负责执行、等待人工验收、解锁和重试。
- `classroom_api.py`：真实课堂 API 适配器；通过临时账号建立 4 导师 + 4 学员房间、发牌、推进阶段并读取快照。RP、账本与 B12 利润分配使用稳定幂等键，失败重试不重复加分或加钱。凭据只存在进程内/本地账号文件，不进入公开状态。
- `static/`：8 个角色可视化窗口（导师 4 + 学员 4），固定 2×4；另有独立 `LIVE RUN SCRIPT` 主控窗口，共 9 窗口。角色网格以 Chrome/macOS 主显示器的 `workArea`（可见安全工作区）为边界，从 `left`/`top` 起铺排，不使用物理显示器 bounds，因此避开菜单栏、左/右 Dock 和 Stage Manager 预留区；第 9 个主控窗口同样必须落在安全工作区内。宽高余数按相邻切线分配，各列、各行最多相差 1 像素。它们显示席位与任务，不替代控制台，也不增加角色席位。学员席保留身份、3 张私密卡、个人 RP、个人钱包和团队资金。

## 状态机

```text
ready --执行--> executing --系统成功--> awaiting-acceptance
  ^                  |                         |
  |                  +--失败----------------> error --重试--> ready
  |                                            |
  +-----------人工验收并解锁 <----------------+
awaiting-acceptance --验收--> 下一块 ready
最后一块验收 --> completed
```

执行是异步的；执行成功不等于通过。只有人工验收会改变 `currentBlockIndex`。每块状态为 `ready / executing / awaiting-acceptance / error / passed`，全局另有 `completed`。

## 数据边界

- 公开控制台状态：块状态、脱敏课堂快照、席位任务、事件时间线、房间/团队公开引用。
- 真实 API 私密数据：登录 Cookie、用户名、密码、房间内部权限；不写入公开状态和文档。
- 学员作品与实体证据：人工保管/验收；系统门槛只检查结构性结果，不能替代导师判断。
- 历史轨与现实轨分离：来源事实、课堂模拟、团队推测分别标记；历史答案在团队冻结判断后才揭晓。
- 规则边界：卡片随机且与身份无关；学员默认不承担 P/D/M/O 职位；单块只有一名当值导师，其余待命。

## 可执行验收

- `tests/run_tests.sh`：无网络的契约、状态机、HTTP、学员视图与布局回归。
- `tests/run_real_acceptance.py`：按 `--course` 驱动隔离真实 API；Google 与饿了么均验证 13 块，且每块仍分别发送 `execute` 与 `accept`，以证明人工闸门不被绕过。
- `tests/verify_live_browser.py`：验证 9 个独立窗口、8 席 2×4 在 `workArea` 安全边界内无重叠且完整覆盖、四学员不同身份/各 3 张私密卡/RP 和两层资金 HUD，以及主控的待验收闸门。

## 课程库与 Run 生命周期

主控课程库提供两个明确的课程 ID：`google-1995-2004`（5 步/13 块完整战役）与 `eleme-2008-find-problem`（5 步/13 块平行世界战役）。切换课程总是新建 Run；已经开始的 Run 必须二次确认。原 API 课堂 Run 仅保留审计，不复用。课程切换后 8 个角色席位同步更新。

饿了么五步平行世界战役固定为：B01 随机发牌；B02 毛线/问题池/AI 守界；B03 五项筛选、反证、历史揭晓并停在 `debrief`；B04 七段连续 360 秒 Demo 并完成。揭晓前所有学员只见安全名“2008 宿舍订餐调查小队”。第1步源于史料；第2—5步为明确标注的玩家平行世界实践，不冒充历史。
