AUTHORING SOP · 不靠猜

制作一门可运行课程

  1. 先看完整性顶部必须显示 5 卡组、每组至少 12 张、Schema 一致。
  2. 再写课程结构五步十三块，每块只给学员一个眼前动作。
  3. 进入抽卡内容用全文搜索反查卡牌，不必翻 JSON。
  4. 守住证据边界F 有来源；R 明说课堂模拟；G 待验证；U 继续调查。
  5. 看学员同款预览确认初中生读得懂，不把导师方法论压给学员。
  6. 检查当前手牌点击 Alpha 手牌 ID，确认稳定 ID 对应正确内容。
  7. 保存不等于生效保存 Candidate 后，原 Run 仍使用旧版。
  8. 人工刷新与验收只有“全部刷新 Alpha”才更新八席；正式课堂绝不静默更新。
