# P2 教师补充概念的来源

2026-09-19 核对；不要求学生背诵或安装框架，不把几个词当作升级必经路线。

- [MCP 官方架构](https://modelcontextprotocol.io/docs/learn/architecture)：连接资料和工具的协议，不规定模型如何推理，也不会赋予未授权能力。
- [Anthropic：Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)：工作流与智能体的组织方式不同；从简单方式开始，按任务需要使用。
- [RAG 原论文](https://arxiv.org/abs/2005.11401)：结合检索资料与生成；找到资料不保证答案正确。

课堂只用少量白话解释，不展示接口名称或版本细节。豆包 Work／WorkBuddy 是用户指定可选工具，本课未核验其所有最新功能，不提供未经验证的产品能力保证。
