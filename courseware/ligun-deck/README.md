# P2 立棍｜120 分钟课件（已部署 r1）

27 页投屏＋教师私有讲稿。扩展原《立棍》，保留设备预约短例，新增校园寻宝整套主棍／六子棍示例和真实试错示范。

- 固定六项：执行者、上下文与项目设计、目标、约束、避免、验收。
- 主棍描述完整游戏，子棍描述各模块；微棍只需知道，AI 负责细拆。
- 全部模块形成可执行核心模板，优先模块启动自己的游戏实操。
- `templates/` 是唯一 Markdown 正文；`workbook/` 提供编辑、复制、下载、打印。
- `demo/` 是预设课堂实例，不冒充学生 AI 结果。
- 旧 `public/courseware/development-mentor-ligun/` 未覆盖。

运行 `npm run build:t132-t133:courseware` 后，按 [共同说明](../shared/README.md) 预览。不要直接打开未构建的源码 HTML，公共引擎与派生 catalog 在构建时加入。
