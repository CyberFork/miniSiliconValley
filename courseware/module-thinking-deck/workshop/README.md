# P1 方块模块工坊 · 阶段 B 可玩样段

对应 TASK-P1-MC-WORKSHOP。此样段不是整套 P1 改造完成回执。先请用户亲自试玩，确认后才进入阶段 C。P2、正式课堂、账号／钱包／作业及现有 P1 r9 均未修改。

## 启动

独立试玩包：解压 `mc-workshop-sample.zip`，在解压目录运行 `sh start.sh`，再打开下方教师地址。若本机已有18135服务，不要重复启动。

源码方式：在项目根目录执行 `npm run dev:mc-workshop`，打开：

- 教师：http://127.0.0.1:18135/workshop/teacher/presenter.html?session=mc-review
- 在教师端点「打开投屏」：同浏览器新窗口，沿用 session/workspace。
- 改用不同 session 是独立作品空间。URL 的 workspace 可显式指定，同 session 不同 workspace 也隔离。

本机服务器仅绑定 127.0.0.1。不使用生产数据、不调用后台。首次需本地服务器提供模块；运行期间引擎资源全部本地加载，不热链 CDN。

## 14 分钟试玩

1. 工具选「放置」，材料选「橡胶」。在正面网格上摆十字：中心与上下左右各一块。鼠标／触摸都可逐格放置。
2. 「选择组合」逐个点选，或「选择全部方块」。写名称、职责，选择轮子行为，保存模块。形状不符合时拒绝并说明。
3. 清空工作台（不删模块库），沿 X 同一行摆两个金属＋一个虚拟燃料。保存推进器。
4. 从模块库选轮子，在四个轮接口各放一份；再把推进器接到推进器接口。接口不能重叠。
5. 进入试驾，按住推进；松开会滑行，刹车减速。黄色标杆进入缓坡，蓝色起伏路，橙色标杆后有落差。可跟随相机、缩放观察。
6. 重置恢复同一辆车／同一起点。回拼装选推进器，转 180°，再试一次，观察相反方向。轮子尺寸始终固定。

可撤销／重做、复制查看模块内部、整体移动到空接口、旋转／拆下实例。改变实例不改模块定义或其他实例。

## 数据契约

`model.mjs` 的 schemaVersion=1 / version=mc-workshop-1：
- blocks：当前工作台整数网格坐标＋材料；最多64块。
- definitions：保存的方块组成、名称、职责、课堂行为；最多16个。
- instances：定义 ID、独立 ID、固定接口、0/180°方向；最多5份。
- 轮子：5块橡胶，XY平面的十字；推进器：同一Y/Z平面，沿X连续「金属、金属、燃料」。不是MC配方。
- 本机自动保存；刷新恢复作品，物理重新开始。JSON导入最大100KB，严格拒绝未知字段、坐标、材料、行为、重复ID／接口和错误配方。导入失败不改当前项目；原始文件不更改。
- 浏览器拒绝存储时保持内存作品、显示持续警告并允许导出。清理浏览器或换设备前请导出。

## 真实物理与简化

`physics.mjs` 使用本地 Rapier 0.20.0 WASM，Three.js 不决定位移。车架为刚体；四个固定半径圆柱轮通过转轴约束连接车架。外观来自用户保存的五个方块，碰撞模型不是五块独立刚体。推进器根据实例方向向车架施力；松开清除力，不清零速度；刹车施加阻力和轮轴阻力矩。

地形为物理三角网格，含平地、缓坡、起伏和落差；没有轨迹插值或强制水平。固定120Hz步进，单帧最多补0.1秒；后台不追赶累积时间。出界冻结并提示重置，不能宣称已完成路线。翻车允许发生；用重置回同一作品和起始条件。不含转向、轮径调节、复杂悬挂或真实燃料计算。

## 唯一模拟来源与展示

教师窗口用 Web Locks 获取该课件版本/session/workspace 的唯一操作锁。第二教师只读，可在原教师退出后显式接管。投屏只渲染带 epoch/sequence 的权威快照，不独立运行物理；不接收旧序号。BroadcastChannel 为主，storage事件降级；不同session/workspace隔离。此样段不承诺跨设备网络投屏。

canvas 使用 ResizeObserver 更新真实像素尺寸／相机视口；展开、全屏、resize不重新创建物理世界或相机。相机模式与方块工具分开，鼠标拖动不会当作放置。触摸可用网格和按住按钮操作。教师讲稿只在 teacher/presenter.html，投屏文件没有教师笔记。

## 失败与后续关卡

WebGL/物理加载失败时停止试驾并显示静态说明＋重试；不能用动画冒充试驾。依赖失败不禁止现有作品导出。

此样段仅本地试玩，尚未部署。进入阶段 C 后还需：完整 P1 替换／四份学习材料／120分钟／末页复习、在真实课件宿主中验证导航焦点、旧 Three.js 场景统一展开机制，以及不可变发布版本。生产网关目前 CSP 未放行 WASM 编译，未来部署须为新课件路径最小化配置 `wasm-unsafe-eval` 并实测，不能全站开启 `unsafe-eval`。不修改历史 r9 及其持久化文字版。

MC原生机制的具体游戏版本确认、用户试玩、目标年龄学生具象性验证、实体iPad／扩展投影屏和完整120分钟试讲均未代签。
